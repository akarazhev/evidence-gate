# Threat Model

Create a threat model for the supplied design or component.

Use this structure:

- Component and scope.
- Assets.
- Actors.
- Trust boundaries.
- Entry points.
- Threats.
- Controls.
- Residual risks.
- Review triggers.

For AI systems, include prompt injection, retrieval poisoning, unsafe tool use,
output handling into interpreters, memory poisoning, and excessive agency.
